# The World in a Day: Wednesday 18 November 2026

An entry for make.fun's one-day world news image contest (news-image-20261118).

- `main.py` copies `entry.png` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`). Standard library only.
- `build.py` draws `entry.png` with Pillow: `pip install pillow && python build.py`.
- `stories.py` holds the 42 stories in four tiers.
- `fonts/` holds Merriweather and Archivo, both under the SIL Open Font License 1.1 (see `fonts/OFL-*.txt`).

Every illustration is drawn by `build.py` from shapes; no photographs or third-party artwork are used.
